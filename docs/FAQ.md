# 常见问题（FAQ）

## 使用相关

### Q: 我需要什么技术背景？

A: 生成项目不需要编程基础，只需回答问题和上传照片。但如果要部署到服务器或二次开发，建议：
- 了解基本的命令行操作
- 会使用 SSH 连接服务器
- （可选）了解 JavaScript/React 可以更好地自定义

### Q: 生成的网站能商用吗？

A: 可以。生成的代码使用 MIT 协议，你可以自由使用、修改、商用，不需要保留版权声明。

### Q: 照片会上传到哪里？

A: 照片处理在本地完成，不会上传到第三方。生成的项目中，照片存储位置由你选择：
- 本地存储：保存在服务器磁盘
- 云存储：上传到你自己的腾讯云 COS / AWS S3 / Cloudflare R2 账号

### Q: 一个网站能放多少张照片？

A: 没有硬性限制，但建议：
- 故事页：3-50 张（太多会影响加载速度）
- 日记应用：无限制（但注意服务器磁盘/云存储空间）

### Q: 支持视频吗？

A: 支持。日记应用可以上传视频，会自动转码为 720p H.264 格式以节省空间和带宽。故事页暂不支持视频（计划在 Phase 2 添加）。

### Q: 可以多人协作吗？

A: 当前版本只支持单人或双人（两个独立账号）。多人协作功能计划在未来版本添加。

## 部署相关

### Q: 需要购买服务器吗？

A: 取决于你选择的技术栈：
- **Node + SQLite**：需要云服务器（最低 1 核 1GB，约 ￥50/月）
- **Serverless**：不需要服务器，使用托管平台（Vercel / Cloudflare，免费额度内可用）

### Q: 推荐哪个服务器提供商？

A: 国内用户推荐：
- **腾讯云轻量应用服务器**：价格便宜，首年 ￥50
- **阿里云 ECS**：稳定可靠，学生机 ￥9.5/月

国际用户推荐：
- **DigitalOcean**：$5/月起
- **Linode**：$5/月起
- **Vultr**：$3.5/月起

### Q: 域名是必须的吗？

A: 不是必须的。可以直接用服务器 IP 访问（如 `http://123.45.67.89:3020`）。但如果想：
- 用 HTTPS（加密传输）
- 更容易分享（域名比 IP 好记）
- 使用 OAuth 登录

那就需要购买域名（约 ￥29/年）。

### Q: 部署到 Vercel 是免费的吗？

A: Vercel 有慷慨的免费额度：
- 100GB 带宽/月
- 无限制的构建次数
- 自动 HTTPS

对个人网站来说完全够用。超出后按量计费。

### Q: 部署失败了怎么办？

A: 先查看错误信息，常见问题：
1. **SSH 连接失败**：检查服务器 IP 和 SSH 密钥
2. **端口占用**：修改 `.env` 中的 `PORT`
3. **权限不足**：确保有写入 `private/` 目录的权限
4. **依赖安装失败**：检查网络和 npm 源

详细排查步骤见 [部署指南 - 故障排除](./DEPLOYMENT.md#故障排除)。

## 功能相关

### Q: 可以修改已生成的网站吗？

A: 可以。生成的项目是完整的源码，你可以：
- 修改样式（CSS）
- 添加新功能（React 组件 + API 路由）
- 更换技术栈（比如改用 PostgreSQL）

详细指南见 [二次开发指南](./CUSTOMIZATION.md)。

### Q: 怎么添加新功能模块？

A: 生成项目时没有勾选的模块，可以后续手动添加：
1. 从模板目录复制对应的前后端代码
2. 在数据库中添加对应的表
3. 在路由中注册新页面

详细步骤见 [二次开发指南 - 添加模块](./CUSTOMIZATION.md#添加模块)。

### Q: 地图功能必须用高德吗？

A: 不是。你可以选择：
- **高德地图**（推荐，国内使用）
- **Mapbox**（国际使用）
- **不要地图**（如果不需要）

也可以自己集成其他地图服务（需要修改代码）。

### Q: 时间胶囊的内容会泄露吗？

A: 不会。时间胶囊在解锁日期前，内容在数据库中是加密存储的，任何 API 都不会返回。只有到了解锁日期，用户主动点击打开，才能看到内容。

## 技术相关

### Q: 为什么选择 SQLite 而不是 MySQL/PostgreSQL？

A: SQLite 非常适合个人网站：
- **零配置**：不需要单独安装数据库服务
- **高性能**：读写速度快，适合小规模数据
- **备份简单**：只需复制一个文件
- **成本低**：不需要额外的数据库服务器

如果你需要更强的扩展性，也可以选择 PostgreSQL 技术栈。

### Q: 视频转码会占用很多服务器资源吗？

A: 视频转码使用 ffmpeg，会占用 CPU。为了不影响网站响应：
- 转码任务放在队列中，一次只处理一个
- 转码完成后自动删除原始视频
- 如果服务器配置低（1 核），建议压缩后再上传，或关闭转码功能

### Q: 为什么要用 React 而不是 Vue/Svelte？

A: React 是当前最流行的前端框架，生态丰富，找资料和解决问题更容易。未来可能会添加其他框架的模板。

### Q: 能用 TypeScript 吗？

A: 当前模板使用 JavaScript，但生成的项目可以自己迁移到 TypeScript。未来可能会添加 TS 模板。

## 安全相关

### Q: 密码安全吗？

A: 密码使用 bcrypt 加密存储，不会明文保存。但单一密码模式的安全性有限，建议：
- 设置强密码（8 位以上，包含数字+字母+符号）
- 定期更换密码
- 不要在公共网络输入密码
- 如果需要更高安全性，选择 OAuth 登录

### Q: 照片会被别人看到吗？

A: 取决于你的配置：
- **密码保护**：只有知道密码的人才能访问
- **服务器安全**：确保服务器防火墙配置正确
- **云存储**：如果使用公开读的 COS bucket，照片 URL 可以被猜到

建议：故事页等私密内容使用密码保护 + 私有存储。

### Q: 数据会丢失吗？

A: 建议定期备份：
- **数据库**：复制 `private/data/diary.db`
- **媒体文件**：复制 `private/photos/` 和 `private/voices/`
- 使用提供的 `scripts/backup.sh` 自动备份到本地/云存储

## 其他

### Q: 为什么叫 Memory Website Builder？

A: 因为这个工具帮你把回忆（Memory）变成网站（Website），用 AI 辅助构建（Builder）。

### Q: 和其他建站工具有什么区别？

A: 主要区别：
- **专注回忆**：不是通用建站，而是专门为回忆网站优化
- **AI 引导**：通过对话生成，不需要学习复杂的建站工具
- **完全掌控**：生成的是源码，不是 SaaS 服务，数据完全属于你
- **开源免费**：MIT 协议，可以自由使用和修改
