# xlovey.cn - XIAO 与英英的回忆网站

第一个使用 Memory Website Builder 生成的完整案例。

## 网站信息

- **在线地址**：[https://xlovey.cn](https://xlovey.cn)
- **主角**：XIAO 与英英（情侣）
- **创建时间**：2024年9月
- **技术栈**：React + GSAP + Express + SQLite
- **部署**：腾讯云首尔服务器（￥50/月）

## 功能模块

### 故事回忆页 (`/story`)
- 35 张照片，从第一次通话到现在
- GSAP 滚动触发动画
- 背景音乐循环播放
- 密码保护（只有两人知道）

### 日记本 (`/`)
- 已写 50+ 篇日记
- 支持照片/视频上传
- 心情图标选择
- 地点标记（高德地图逆地理编码）

### 相册 (`/album`)
- 按日期浏览所有照片
- 瀑布流布局
- 点击查看大图

### 纪念日 (`/days`)
- 相识日、恋爱日、生日等重要日期
- 正计时显示（已经 XX 天）
- 倒计时显示（还有 XX 天）

### 愿望清单 (`/wishes`)
- 记录想一起做的事
- 完成后打勾
- 可以关联日记（完成时写下感受）

### 时间胶囊 (`/capsules`)
- 写给未来的信
- 设定解锁日期
- 到期前无法查看内容
- 记录第一次打开的时间

### 恋爱地图 (`/map`)
- 标记去过的地方
- 路线回放动画
- 省份高亮显示
- 手绘风格标记（蜡笔图标）

### 留言评论
- 每篇日记下可以留言
- 支持回复
- 实时更新

## 设计特色

### 手绘蜡笔风格
- 45 个手绘图标（AI 生成）
- 贴纸按钮风格
- SVG 蜡笔滤镜效果
- 温暖治愈的配色

### 响应式设计
- 完美适配手机/平板/桌面
- PWA 支持（可添加到手机桌面）
- 触摸友好的交互

## 技术亮点

### 前端
- React 18 + React Router DOM 6
- GSAP 3.12 (ScrollTrigger)
- 自定义 SVG 蜡笔滤镜
- 响应式图片（WebP 格式）

### 后端
- Express 5 + better-sqlite3
- IP 限流（防刷接口）
- JWT 签名（故事页媒体访问）
- ffmpeg 视频转码（720p H.264）

### 部署
- Nginx 反向代理
- systemd 守护进程
- 一键部署脚本
- 自动健康检查

### 地图
- 高德地图 JS API 2.0
- 自定义绘本风标记
- 省份区划高亮
- GPS 坐标系转换（WGS-84 → GCJ-02）
